# 三 Tab 分类参数卡与原生编辑实施计划

- 时间：2026-10-12（北京时间；实施日志另记秒级时间）
- 已批准：页面内编辑取代设置页首页参数编辑；仪表盘、电池、控制器卡片化。
- 保持五 Tab、iOS 16、原生导航与本机隐私边界；不改 BLE 协议/查询、不写设备参数。

## 实施切片
1. Foundation-only v3 页面布局模型与回归测试：稳定指标 ID、分类内插入排序、仪表盘顶部/来源区移动、替换归还、显隐、唯一性、旧配置迁移。
2. 原生 UICollectionView 网格与 SwiftUI 参数卡：一页一个滚动容器，原生本地拖放、局部数据刷新、动态高度、大字号/减少动态效果。
3. 电池/控制器分类参数目录与展示；连接/过期/故障提示不因隐藏而消失。单体/探头真实编号与布局位置分离。
4. 仪表盘接入同一编辑会话；曲线固定在顶部与来源区之间，来源隔离，替换经菜单而非拖动。
5. 移除设置页旧入口，更新静态契约、App/域/UI 测试与设计文档。

## 事务与兼容
- 每个 Tab 独立偏好与草稿；完成才保存，取消回退。
- 默认保留原 27 首页指标位置与所有有效自定义/归还指标；v1/v2 只读迁移到新 key，保留旧 JSON。
- 拖动只移动，不复制、不隐式替换；隐藏与原指标归还保留目录。
- 新通道只按协议上限（64 单体、16 探头）识别；上报数量减少不删掉持久化排序。
- 未保存草稿切 Tab 时保留；外部拖放与其他网格拖放拒绝。

## 验证与交付边界
- 修改前运行已有 Python 静态契约；域模型新测试优先。
- Windows 本机未检测到 swift/xcodebuild；不得声称 Swift 编译/XCTest/XCUITest 成功。
- 先做本地可执行静态检查与差异核对；macOS CI/模拟器及 iPhone/BMS 的实际验证分别记录。
- 本轮不自动提交、推送或部署；保留独立 iOS 仓库边界。

## 独立审阅后的修正
- 集合网格重复 item 不使用整组 fractionalWidth；按真实可用宽度扣除 32pt 左右内边距和每列 8pt 间距，再计算 absolute 列宽。普通 2 列/宽屏 3 列需 UIKit frame 运行回归，不只检查辅助字号单列。
- UIKit hosted 单元格内不依赖 NavigationLink 环境；续航/控制器历史用状态请求，外层 navigationDestination 承接。
- MOS 部分缺失保留未知；恢复默认通道按真实编号而非保存的用户顺序重建。
- VoiceOver 非编辑时只提供编辑入口，不提供无效果的排序动作；编辑时提供移动、隐藏与来源归还。
- UI 布局套件前缀必须匹配生产 UITest-Home- gate，所有重启保持同套件并禁用真实 BLE。

## 仍需运行验收
- Windows 无 swift/xcodebuild，本轮所有新 XCTest/XCUITest 尚未执行。
- 50ms 控制器遥测下 visible hosting configuration 刷新没有设置限频，需 Instruments 确认主线程/self-sizing/内部分支状态成本；不依据静态无reload就宣称流畅。
- 拖动期间延后结构快照，仅提起卡保留预览，其余可见卡继续更新有效性；拖动长时间、边缘自动滚动、混合卡片尺寸与减少动态效果需真实设备复核。
