# Dashboard 页面约束（2026-10-11）

以用户最新决定与 MASTER.md 的最后有效约束为准；旧线框图不是施工依据。

## 当前页面结构

- 根页没有“安途”标题、导航栏占位、固定 header、BMS 连接卡或行程控制卡。
- 参数从顶部安全区直接开始；全部参数/图表采用同一个连续纵向滚动容器，不创建嵌套滚动区。
- 续航详情入口放在现有参数卡或图表标题行中，随内容滚动；详情恢复原生导航栏与返回。
- 系统状态栏、刘海、底部五个 Tab 与原生返回行为保留，不以越过安全区模拟全屏。
- 保留 27 默认槽位及用户自定义/旧版布局偏好；删除的是首页固定辅助卡，不是持久化指标。
- 竖屏保留高密度；横屏按实际可用宽度分栏。字号放大可减少列数/抬高卡片，不裁剪、不极端缩小文字。
- BMS 连接管理在设备 Tab，开始/结束、当前会话及保存/错误恢复在行程 Tab。

## 指标与图表

- 数值使用 Dynamic Type、用户数值比例和等宽数字；未知/过期值显示 --，不造零值。
- 内容卡片使用系统分组背景，不扩大 Liquid Glass 到指标/图表内容层。
- 业务曲线使用系统 Swift Charts，不新增第三方依赖。
- 功率仍取有效 snapshot.power（W），不能把电流（A）改名成瓦特。
- 缺失/非有限值、非递增时间与超过 5 秒的间隔断线；禁止跨缺口连线。
- 显示单位、接收时间/样本范围、历史性质与文字摘要；等待数据不能画成平线。

## 回归与验收

- 默认/最大辅助字号；375pt/大屏/横屏；浅色/深色；VoiceOver/减少动态效果。
- 根页无导航栏空行，续航详情有系统返回，返回根页恢复无导航栏。
- 行程在空历史、已有历史、记录中/暂停/保存失败状态下均有可达操作。
- 所有槽位保持可滚动到达，底部 Tab 不遮住最后一行。
- Windows 源码/语法检查不是 Xcode 编译；macOS CI/模拟器与真机验收分别登记到 CONSTRUCTION_LOG.md。
